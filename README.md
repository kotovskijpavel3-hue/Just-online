# Just Online

Комната с живыми курсорами. Открываешь ссылку — видишь, где сейчас мышь у других людей, и можешь повесить комментарий, который будет висеть прямо над твоим курсором.

## Что умеет

- Все курсоры видны вживую: позиция передаётся с частотой до 25 раз в секунду.
- Комментарий к курсору: пишешь в поле снизу, жмёшь Enter — текст закрепляется над курсором и виден всем. Esc — убрать.
- У каждого свой цвет и имя (имя можно поменять в шапке).
- Клик по полю — волна-отклик.
- Координаты нормализованы (0…1), поэтому курсоры корректно отображаются на экранах разного размера.
- Комментарии живут в памяти сервера: новый участник сразу видит, что написано у остальных. После перезапуска сервера — очищаются.

## Стек

- Node.js, без фреймворков: `http` для статики + `ws` для WebSocket.
- Фронтенд — чистые HTML/CSS/JS, без сборки.

## Запуск локально

```bash
npm install
npm start
```

Открыть http://localhost:3000. Чтобы проверить «мультиплеер», открой вторую вкладку — курсоры увидят друг друга.

## Структура

```
server.js          HTTP-статика + WebSocket-хаб (комнаты в памяти)
public/index.html  разметка
public/style.css   оформление, анимации
public/app.js      WebSocket-клиент, отрисовка курсоров, ввод комментариев
render.yaml        конфиг для деплоя на Render
```

## Деплой на Render

### Вариант 1 — Blueprint (в репозитории уже есть render.yaml)

1. Зайти на [render.com](https://render.com) через GitHub.
2. **New +** → **Blueprint**.
3. Выбрать репозиторий `Just-online` → **Connect**.
4. Render сам прочитает `render.yaml` → **Apply**.

### Вариант 2 — вручную

1. **New +** → **Web Service** → подключить `Just-online`.
2. Настройки:
   - Runtime: **Node**
   - Branch: **main**
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: **Free**
3. **Create Web Service** → ждать сборку → получить адрес вида `https://just-online-xxxx.onrender.com`.

Сервер слушает `process.env.PORT`, поэтому дополнительные настройки порта не нужны. WebSocket на Render работает на Web Services (Static Site не подойдёт — там нет сервера).

### Ограничения бесплатного плана

- Сервис засыпает после ~15 минут без трафика; первый заход после сна — 30–60 секунд.
- Состояние в памяти: после перезапуска комментарии и позиции обнуляются.
